
# Personal Portfolio Website

## About the Project

This project is a personal portfolio website created to showcase my skills, interests, and programming projects. The website includes sections for my introduction, skills, projects, and contact information.

## Technologies Used

- HTML
- CSS
- JavaScript

## AI Tool Used

ChatGPT was used as an AI assistant during the development of this project.

## How AI Helped

ChatGPT helped generate the initial structure of the webpage and provided suggestions for improving the HTML layout, CSS styling, visual design, responsiveness, and JavaScript functionality.

## Features

- Responsive navigation
- About section
- Skills section
- Project section
- Contact section
- Social media links
- Responsive design for mobile devices
- Interactive navigation functionality
